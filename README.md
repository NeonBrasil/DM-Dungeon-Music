# ⚔️ DM - Dungeon Music

Mesa virtual no estilo Roll20/HubRPG, com geradores de mapa no estilo Watabou. Roda no PC do mestre; os jogadores entram pelo navegador, sem instalar nada.

O projeto fica em [`vtt/`](vtt/). Como abrir, recursos e desenvolvimento: [vtt/README.md](vtt/README.md).

O antigo app desktop em Python foi removido; a última versão dele está no commit `6fd0989`.
